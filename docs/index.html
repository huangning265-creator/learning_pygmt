PyGMT 地球科學繪圖

歡迎來到現代地球物理學的繪圖世界！這份指南將帶你了解如何使用 Python 結合 GMT 的強大功能，繪製出期刊等級的科學圖表。

💡 為什麼選擇 PyGMT？

簡單、直覺、美觀。它將複雜的 GMT 指令包裝成 Python 函式，讓科學家能專注於數據分析，而不是被語法卡住。

🛠️ 快速安裝指南

工欲善其事，必先利其器。建議使用 Conda 來管理環境，以確保所有依賴套件 (如 Ghostscript) 都能正確安裝。

# 1. 建立虛擬環境
conda create --name pygmt python=3.9

# 2. 啟用環境
conda activate pygmt

# 3. 安裝 PyGMT (透過 conda-forge)
conda install --channel conda-forge pygmt

🌍 基礎繪圖：海岸線

這是所有地圖的起點。使用 coast 方法，我們可以輕易畫出世界地圖、填色，並加上經緯度邊框。

import pygmt

fig = pygmt.Figure()
# 繪製海岸線：麥卡托投影，寬 15cm
fig.coast(
    region="g",
    projection="M15c",
    land="gray",
    water="lightblue",
    frame="a"
)
fig.show()
▲ PyGMT 輸出的標準海岸線地圖 (來源：PyGMT Gallery)

🌋 進階魔法：繪製地形網格 (grdimage)

還在手動下載 DEM 數據嗎？PyGMT 內建 load_earth_relief，一秒鐘載入全球地形數據！

# 1. 自動下載全球地形數據 (解析度 1度)
grid = pygmt.datasets.load_earth_relief(resolution="01d")

fig = pygmt.Figure()
# 2. 繪製網格影像，使用 "geo" 色階
fig.grdimage(grid=grid, projection="R12c", cmap="geo")
# 3. 加上色彩條 (Colorbar)
fig.colorbar(frame=["a2500", "x+lElevation", "y+lm"])
fig.show()
▲ 使用 grdimage 繪製的全球地形與色彩條 (來源：PyGMT Gallery)

✈️ 實戰應用：大圓航線

結合我們學到的技巧，這是一個「布宜諾斯艾利斯 -> 法蘭克福 -> 約翰尼斯堡」的飛行路徑圖。注意我們使用了 style="q..." 來製作沿著線條排列的文字。

import pygmt

fig = pygmt.Figure()
fig.coast(region="d", projection="M15c", land="lightgray", water="azure")

lons = [-58.4, 8.68, 28.04]
lats = [-34.6, 50.11, -26.20]

# 繪製紅色虛線航線，並加上文字標籤
fig.plot(
    x=lons, y=lats, 
    pen="2p,red,dashed",
    style="qN+1:+l\"World Tour\"+f10p,Helvetica,red"
)
fig.show()
▲ 透過 plot 指令繪製的大圓路徑示意 (來源：PyGMT Gallery)
