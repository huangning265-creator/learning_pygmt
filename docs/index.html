📝 課程一：繪製地球地形 (Earth Relief)

PyGMT 最強大的功能之一，就是能直接從遠端伺服器下載地形數據並繪圖。我們不需要自己準備龐大的數據檔，一行指令就搞定！

1. 下載數據 (Load Data)

使用 load_earth_relief 函數。我們可以設定解析度 (resolution)，例如 "01d" 代表 1弧度 (1 arc-degree)。

import pygmt
# 下載全球地形數據，解析度為 1 度
grid = pygmt.datasets.load_earth_relief(resolution="01d")

2. 繪製網格影像 (Create a Plot)

使用 grdimage 方法來視覺化網格數據。它會根據 Z 值 (高度) 自動填色。

  • projection (投影): 設定地圖投影法。例如 "R12c" 代表寬 12 公分的 Winkel Tripel 投影。
  • cmap (色階): 設定顏色表。常用選項有 "geo" (地理)、"relief" (地形) 或預設的 "turbo"。
fig = pygmt.Figure()
# 繪製地圖：設定投影為 Winkel Tripel，色階為 'geo'
fig.grdimage(grid=grid, projection="R12c", cmap="geo")
# 加入 Colorbar：設定刻度間隔為 2500，並標註軸標籤
fig.colorbar(frame=["a2500", "x+lElevation", "y+lm"])
fig.show()
▲ 全球地形圖 (Winkel Tripel 投影 + Geo 色階)

🔍 課程二：鎖定特定區域 (Region Map)

我們通常只需要研究某個國家或地區。這時可以使用 region 參數來裁切數據。

注意：當解析度高於 5 arc-minutes (例如 "10m") 時，必須指定 region 範圍，才不會下載太多數據把電腦跑當機！

# 載入解析度 10m 的數據，範圍鎖定在歐洲 [經度最小, 經度最大, 緯度最小, 緯度最大]
grid = pygmt.datasets.load_earth_relief(resolution="10m", region=[-14, 30, 35, 60])

fig = pygmt.Figure()
# 使用 Mercator 投影 (M)，寬度 15cm，並加上邊框 (frame="a")
fig.grdimage(grid=grid, projection="M15c", frame="a", cmap="geo")
fig.colorbar(frame=["a1000", "x+lElevation", "y+lm"])
fig.show()
▲ 歐洲區域地形圖 (Mercator 投影)
