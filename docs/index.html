🚀 什麼是 PyGMT？ (繪圖界的超級英雄)

簡單來說，PyGMT 是 **Python 語言** 和 **GMT 繪圖工具** 的完美結合。 以前，GMT 雖然強大，但操作複雜；現在有了 PyGMT，你不需要離開舒服的 Python 環境，就能用簡潔的語法，畫出**等值線、地質剖面、海平面異常、地震活動圖**等各種專業的地學圖件。

💡 為什麼要用 PyGMT？ (三大核心優勢)

  • **原生 Python 體驗 (🐍 Pythonic!)：** PyGMT 的語法高度 Python 化，使用 **Pandas** 和 **Xarray** 處理數據，再用 PyGMT 繪圖，一氣呵成！
  • **頂級視覺效果 (🎨 Aesthetic!)：** GMT 數十年來在地球科學領域累積的**專業色彩學**和**精準投影**技術，讓你的圖表直接達到學術期刊的發表標準。
  • **極致效率與「鍊式操作」 (🔗 Chaining!)：** 它支援強大的**鍊式操作 (Chaining)**。你不再需要為每個繪圖步驟寫一堆重複的程式碼，只要用 `.` 點下去，就能繼續下一步！

⚙️ 核心魔法展示：鍊式操作 (Chaining)

這就是 PyGMT 最迷人的地方。想繪製一張海岸線，並在上面疊加基圖？一個點號就搞定！

# 1. 召喚 PyGMT 魔法師！
import pygmt

# 2. 開始鍊式操作：fig (畫布) 點下去，功能就出來了！
fig = pygmt.Figure()
fig.basemap(region="g", projection="W15c", frame=True)
.coast(land="gray", water="lightblue", borders=["1/thin"])
.show() # 畫出全球地圖！超簡單！

🛠️ 快速上手：如何召喚魔法棒？

因為 PyGMT 依賴 GMT 核心程式，建議使用 `conda` 或 `mamba` 來安裝，這是最穩定的方法：

# 在你的 Anaconda/Mamba 環境中執行：
conda install -c conda-forge pygmt

(💡 小提示：如果你已經在 Codespace 或 Colab 上，可以直接用 `pip install pygmt` 試試喔！)
