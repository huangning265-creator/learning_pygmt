✈️ PyGMT 實戰：重構飛行航線圖

— 分析 GMT Short Course Lecture 3，用 Python 重新演繹！ —

📺 分析來源影片： GMT Short Course - Lecture 3 - Symbols and Lines

這部影片示範了如何在舊版 GMT 中繪製線條、多邊形以及「帶文字的曲線 (Quoted Lines)」。原本的 Bash 語法雖然強大，但寫起來略顯繁瑣。今天，我們用 PyGMT 把這一切變得簡單又優雅！

🔍 重點分析：我們學到了什麼？

  • 📍 Quoted Lines (引用線)： 這在繪製航線、斷層線或等高線時超好用！它能讓文字沿著曲線彎曲排列，而不是死板的水平顯示。
  • 🌐 Great Circles (大圓航線)： 在地圖上，兩點之間最短的距離不是直線，而是大圓路徑。PyGMT 會自動幫我們計算這條彎曲的路徑。
  • ✨ Custom Symbols (自訂符號)： 雖然影片教了如何寫 .def 檔，但在 PyGMT 中，我們可以直接用內建符號或簡單的指令來標示機場。

💻 重構後的 PyGMT 程式碼

這段程式碼重現了影片中「布宜諾斯艾利斯 -> 法蘭克福 -> 約翰尼斯堡」的經典範例。注意看我們如何用 style="q..." 這個魔法參數來實現文字沿線排列！

import pygmt

# 1. 建立畫布，設定麥卡托投影 (Mercator)
fig = pygmt.Figure()
fig.coast(
region="d", # 全球範圍 (Data domain)
projection="M15c", # 麥卡托投影，寬 15 公分
land="lightgray", # 陸地顏色
water="azure", # 海洋顏色
borders="1/0.5p", # 繪製國界
frame="a" # 自動邊框
)

# 2. 定義航點資料：[經度, 緯度, 標籤]
# 布宜諾斯艾利斯 -> 法蘭克福 -> 約翰尼斯堡
flights_lon = [-58.4, 8.68, 28.04]
flights_lat = [-34.6, 50.11, -26.20]
labels = ["Buenos Aires", "Frankfurt", "Johannesburg"]

# 3. 繪製「帶文字」的飛行航線 (Quoted Line)
# style="q..." 是核心魔法！
# n1:+l"Flight Path" 表示線上只有 1 個標籤，內容為 "Flight Path"
fig.plot(
x=flights_lon, y=flights_lat,
pen="2p,red,dashed", # 紅色虛線
style="qN+1:+l\"World Tour 2025\"+f10p,Helvetica-Bold,red"
)

# 4. 標示機場位置 (繪製星星符號)
fig.plot(
x=flights_lon, y=flights_lat,
style="a0.5c", # a = star (星星), 大小 0.5cm
color="yellow",
pen="1p,black"
)

# 5. 加上城市名稱文字
fig.text(
x=flights_lon, y=flights_lat,
text=labels,
font="12p,Helvetica-Bold,black",
justify="BL", # 對齊方式：Bottom Left (文字在點的右上方)
offset="0.2c/0.2c" # 稍微偏移一點，不要蓋住星星
)

fig.show()

🚀 為什麼這比 Bash Script 更好？

以前在 Bash 裡，你可能要手動建立暫存文字檔、處理複雜的字串輸入。在 PyGMT 裡，我們直接使用 Python 的 List (列表) 來管理經緯度，甚至可以輕鬆結合 Pandas 資料庫。這讓數據處理和繪圖邏輯完美結合，程式碼的可讀性（Readability）也大幅提升！
